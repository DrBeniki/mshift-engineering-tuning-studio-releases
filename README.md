# M-Shift Engineering Tuning Studio downloads

Windows tuning and diagnostics for MSS65 DME and SMG III TCU, including MSHFT Ultra.
This repository hosts downloads only, not proprietary application source.

## Download v17.2.1

[Windows installer — v17.2.1](https://github.com/DrBeniki/mshift-engineering-tuning-studio-releases/releases/download/v17.2.1/MShiftEngineeringTuningStudioSetup_v17.2.1.exe)

[Release notes and SHA-256 file](https://github.com/DrBeniki/mshift-engineering-tuning-studio-releases/releases/tag/v17.2.1)

This installer is unsigned. Windows may display an unknown-publisher warning.
Verify the downloaded file against the release checksum before running it.
Studio checks for newer releases when opened and offers the installer download; updates are not installed automatically. Previous releases remain available for rollback.

## Licences

- Basic DME features are free.
- Premium and Ultra are distinct, VIN-bound products. Ultra is available by
  private application / price on application: [info@mshiftengineering.com](mailto:info@mshiftengineering.com).
- Ultra includes SMG III TCU tuning. VIN assignment happens when connected to the
  DME; do not manually enter a VIN to obtain an entitlement.
- Initial activation and Ultra access provisioning require internet. Subsequent
  Ultra installation/tuning works offline for that Windows account and release.
  Another computer/account or content release requires provisioning again.

The installer includes the separate GPL DME helper, its corresponding source,
licences and diagnostics resources. No additional helper download is required.

For controlled motorsport/off-road use. Keep stable power and a compatible
K+DCAN cable connected throughout any flash. Installing Studio alone does not
flash the DME. Never interrupt a flash to install a software update.
